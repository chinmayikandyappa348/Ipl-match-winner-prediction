# IPL Match Winner Prediction

## Project Title
IPL Match Winner Prediction Using Machine Learning

## Description
This project predicts the winner of an IPL match based on:
- Team 1
- Team 2
- Venue
- City
- Toss Winner

The project is developed using Python, Flask, HTML, CSS, and Machine Learning.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Scikit-learn
- Pandas
- Joblib

## Files
- app.py - Flask application
- train_model.py - Trains the machine learning model
- model.pkl - Saved trained model
- ipl.csv - Dataset
- templates/index.html - Web page
- static/style.css - Styling

## How to Run
1. Open the project in PyCharm.
2. Run train_model.py (if model.pkl is not created).
3. Run app.py.
4. Open http://127.0.0.1:5000 in your browser.
5. Enter the match details and click Predict Winner.
